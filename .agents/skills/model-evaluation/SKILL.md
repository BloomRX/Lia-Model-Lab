# model evaluation

Read docs/07-AVALIACAO-E-GATES.md and experiment governance. Define tasks, metrics, critical failures and thresholds before seeing results. Compare base and adapter with matching revision, tokenizer, template, prompts, tools, decoding and environment. Isolate holdouts and document leakage controls. Evaluate pt-BR, instruction following, uncertainty, persona, context, tool-use, safety and applicable modalities. Explain metric limits; subjective quality needs human review. Record failures, latency, consumption, hardware, versions and parameters. Report gains and regressions per capability. Never tune on holdout or treat one successful response as proof.
