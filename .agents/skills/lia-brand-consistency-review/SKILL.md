# lia brand consistency review

Read docs/BRAND-STANDARDS.md and the product/platform guide. Confirm official name, purpose, branch and real integration status. Verify integrations are optional and no hidden dependency appears. Distinguish implemented, planned, experimental and untested. Check privacy, costs, authorization, data paths and secrets. Separate code, model, dataset, asset and brand licenses. Distinguish AI weights from avatar assets, agent runtime from inference engine, and Lia memory from developer memory-bank. Return OK/RISK/PENDING with file evidence. Do not alter logos, brand rights or product policy without approval.
