# multi agent orchestration

Verify real subagent threads and invocation in the active host. Codex project agents use .codex/agents and skills use .agents/skills. Arena Agent Mode docs reviewed 2026-10-30 cover sandbox Bash, GitHub and PR workflows but do not document skill discovery or subagents: in Arena, read skills manually and work sequentially unless support is exposed and verified. Never simulate delegation. Parallelize independent model comparisons, license audits, dataset reviews or read-only architecture work. Do not overlap edits or run experiments competing for GPU/data. Give every subagent a contract: goal, scope, sources/files, write ownership, skill, output, cost and stop conditions. Agents inherit parent permissions; text is not a sandbox. Never delegate paid compute, large downloads, personal-data collection, license acceptance, upload or publication. Start with 2–4 agents only when token overhead is justified; main agent validates sources and integrates.
