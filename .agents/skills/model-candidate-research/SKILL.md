# model candidate research

Read the Model Lab selection and architecture docs. Define Lia tasks/constraints first. Use official model cards, repositories, release notes and license terms. Pin exact revision and record URL/date. Compare architecture, active/total parameters, context, tokenizer/template, pt-BR, modalities, tool use, SFT/LoRA/QLoRA support, distribution restrictions and runtime compatibility. Distinguish inference quantization from training quantization; GGUF is not automatically a fine-tuning source. Estimate inference, training and serving memory separately with stated assumptions. Report facts, vendor claims, hypotheses, unknowns, sources and a conditional recommendation. Do not download weights, call paid APIs, accept terms or provision GPU.
