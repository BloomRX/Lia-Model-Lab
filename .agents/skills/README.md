# Skills do Lia Model Lab

Procedimentos versionados; descoberta automática no Arena não foi comprovada. Leia manualmente a skill aplicável. O principal segue o procedimento em sequência se o host não expuser spawn/wait real. Não simular delegação. [AGENTS](../../AGENTS.md) e [ownership/fallback](../../docs/14-ORQUESTRACAO-DE-AGENTES.md).

| Procedimento | Saída |
|---|---|
| [model-candidate-research](model-candidate-research/SKILL.md) | Comparação de checkpoints e recomendação condicional |
| [capability-mapping](capability-mapping/SKILL.md) | Responsabilidades, contratos e teste operacional |
| [dataset-governance](dataset-governance/SKILL.md) | Card, direitos/privacidade e splits |
| [finetuning-plan](finetuning-plan/SKILL.md) | Plano SFT sem execução |
| [experiment-reproducibility](experiment-reproducibility/SKILL.md) | Identidade/hashes/retomada |
| [model-evaluation](model-evaluation/SKILL.md) | Comparação por capacidade/regressões |
| [model-license-release-review](model-license-release-review/SKILL.md) | Obrigações e bloqueios por artefato |
| [multi-agent-orchestration](multi-agent-orchestration/SKILL.md) | Ownership e síntese real/fallback |
| [lia-brand-consistency-review](lia-brand-consistency-review/SKILL.md) | OK/RISK/PENDING com evidência |

Nenhuma skill concede autorização de custo, treinamento, dados pessoais, upload ou publicação. Mantenha escopos distintos em vez de usar todos os procedimentos para qualquer alteração.
