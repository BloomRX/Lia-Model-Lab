# model license release review

Read dataset and experiment governance plus model/dataset cards. Inspect primary license terms for exact revisions. Separate rights for code, base weights, adapters, merged weights, datasets, synthetic data, voice models, assets and Lia brand. Record commercial use, redistribution, attribution, notices and derivative restrictions. Verify data permissions cover training/evaluation/release. Check hashes, inference instructions, quantization, metrics and limitations. Return an artifact-by-artifact obligations matrix and blockers. Do not accept terms, upload, publish or give legal advice. Unknown or incompatible terms block release.
